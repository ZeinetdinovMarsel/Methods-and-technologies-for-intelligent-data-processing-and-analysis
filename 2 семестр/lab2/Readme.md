
# Билд готов только под тестирование

## Запуск

### 1. Обучение модели
Для обучения модели используйте скрипт:
```bash
python train_model.py
````

### 2. Тестирование модели

Для тестирования обученной модели используйте скрипт:

```bash
python test_model.py
```

### 3. Запуск сервера и клиента

1. Сначала запустите сервер.
2. Затем запустите клиент по пути:

```bash
Checkers/Build/Checkers.exe
```
